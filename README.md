# 🌐 Portfólio Pessoal | Carlos Eduardo

### Desenvolvedor de Software | Full Stack • Mobile • Desktop

Bem-vindo ao repositório do meu portfólio pessoal!

Desenvolvi este site para apresentar minha trajetória na área de tecnologia, minhas competências e os projetos que venho construindo ao longo da minha formação como desenvolvedor.

O projeto foi desenvolvido com **HTML5, CSS3 e JavaScript puro**, sem frameworks, priorizando uma identidade visual moderna, responsividade, interatividade e uma navegação intuitiva.

## ⚙️ Como executar localmente

**1. Clone o repositório:**

```bash
git clone https://github.com/CarlosEduardoFSousa/MeuPortifolio.git
```

**2. Acesse o diretório do projeto:**

```bash
cd MeuPortifolio
cd "Portifólio"
```

**3. Abra o arquivo `index.html` em seu navegador.**

Não é necessário instalar dependências ou configurar frameworks.
